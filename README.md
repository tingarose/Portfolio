# Ivy Lee Portfolio

Personal portfolio built with Next.js, React, TypeScript, and Tailwind CSS.

Use Node.js 22.x and install dependencies with `npm ci`.

- `npm run dev` starts the development server.
- `npm run build` creates the production build.
- `npm start` serves the production build.

Vercel settings are in `vercel.json`. The `public/` directory contains the assets required by the site.
